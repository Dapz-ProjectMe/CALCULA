# CALCULA V2.0

Professional Digital Calculator — Student Project.

Developer: Daffa Nurkhalish
Class: X APAT 1
Year: 2026

## Run
Buka `index.html` di browser.

Untuk fitur PWA/service worker, jalankan melalui local server, misalnya VS Code Live Server.

## Current features
- Dashboard
- Basic calculator
- Calculation history
- LocalStorage
- Dark/light mode
- Responsive layout
- Keyboard support
- PWA manifest + service worker
- Project profile

## Next development
Scientific calculator, unit converter, finance calculator, BMI calculator, richer offline support, testing, accessibility audit, and Android packaging.
